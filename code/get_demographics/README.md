# Demographics

As participants were added, I queried additional demographics for those
participants, meaning that there are a growing number of files that are combined
and de-duped in `format_demographics2.R`.

`format_demographics.R` is outdated and not used.

## Values used

- Demographics (raw): `1.1` (date of stroke), `1.2` (DoB), `1.5` (sex)
- WAB (summary): `WAB Aphasia Quotient`
- EHI (summary): `LateralityIndex`
